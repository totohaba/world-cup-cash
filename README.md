# World Cup Cash

World Cup Cash is a private family World Cup picks game.

This prototype is a mobile-first web app for iPhone Safari. The planned v1 stack is:

- GitHub Pages for static app hosting
- Google Apps Script for the backend/API
- Google Sheets as the live data store

## Current Prototype Scope

The first prototype focuses on Group Matchday 1:

- player join flow
- active match list
- pick saving
- live leaderboard
- manual result settlement

## Project Files

- `world_cup_cash_game_spec_v4.md`: product/game specification
- `world_cup_cash_technical_spec_v1.md`: technical specification
- `google_apps_script_backend_v1.gs`: local backup of the Apps Script backend
- `world_cup_cash_google_sheets_template_v1.xlsx`: Google Sheets database template
